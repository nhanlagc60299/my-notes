# 📓 Sổ ôn tập — AI Agents

Mỗi lần kiểm tra (câu khởi động, câu hỏi trong buổi, quiz checkpoint, kể cả phiên mini) đều được ghi vào một file `NN-<ten-buoi>.md` ở thư mục này. Phiên mini thì ghi thêm vào file của buổi đó. Mở ra lúc rảnh để ôn, trên điện thoại cũng đọc được.

**Cách ôn để nhớ lâu** (retrieval practice, Dunlosky et al. 2013): đọc câu hỏi, tự trả lời, rồi mới mở "Đáp án". Đọc lại đáp án mà không tự trả lời trước thì gần như vô ích. Ôn câu ❌ trước. Câu nào sai 2 lần thì thành flashcard.
